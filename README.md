# 원료 저장설비 Type별 면적 계산 Tool

제철소·발전소의 원료(석탄·철광석·부원료) 저장설비를 **오픈야드 / Shed / 원형 Silo** 세 가지 타입으로
검토했을 때의 소요 면적을 산출하고, 실비례 도면과 3D 부지로 함께 보여주는 단일 HTML 도구입니다.

## 바로 쓰기

주소만 열면 바로 씁니다 — 설치도 서버도 필요 없습니다.
파일 하나짜리라 그대로 내려받아 사내망·오프라인에서도 그대로 돌아갑니다.

## 내려받아 쓰기 / 직접 빌드

```bash
python assemble.py
```

`원료저장설비-면적계산.html` 한 파일이 생성됩니다. 브라우저로 열면 끝이고,
외부 서버·인터넷 연결이 필요 없습니다 (Three.js 포함 전부 인라인).

빌드 산출물은 저장소에 넣지 않습니다 — 소스와 산출물이 어긋나면 어느 쪽이 맞는지
알 수 없게 되므로, 배포본은 항상 GitHub Actions 가 새로 만듭니다
(`.github/workflows/pages.yml`). 시험이 깨지면 배포하지 않습니다.

## 시험

```bash
node tests/run-all.js
```

프레임워크 없이 node 내장 `assert` 만 씁니다. 마지막 항목 `verification` 은
예시 설비(야드 A·B, Shed, Silo, 통합 배치)의 골든값을
그대로 재현하는지 검사하는 회귀시험입니다.

## 구성

| 폴더 | 내용 |
|---|---|
| `js/rsd-core.js`, `rsd-math.js`, `rsd-data.js` | 공통 계산·물성·기본값·검증 프리셋 |
| `js/rsd-engine-*.js` | 야드 / Shed / Silo / 마스터플랜 계산 엔진 |
| `js/rsd-draw2d*.js` | 평면·단면·마스터플랜·파라미터 도해 (SVG, 미터 좌표) |
| `js/rsd-draw3d.js`, `rsd-equip3d.js` | 3D 부지 (Three.js) |
| `js/rsd-ui-*.js`, `rsd-app.js` | 화면·상태 관리 |
| `css/rsd.css`, `html/template.html` | 스타일·틀 |
| `tests/` | 시험 (`run-all.js` 가 전부 실행) |

## 주요 기능

| 탭 | 내용 |
|---|---|
| ① 원료·용량 | 연간 사용량·재고일수·저장타입·운영효율 → 설계 대상용량 |
| ② 오픈야드 | 열 수 산정 · 평면/단면도 · 파일 제원(원료별) |
| ③ Shed | 단면 ①②③ 영역 분해 · 셀 구성(자동/직접) · 평면도 |
| ④ Silo | 용량에서 제원 산출(상사 확대) · 열 배치 대안 비교 |
| ⑤ 타입 비교 | 같은 원료를 세 타입으로 놓았을 때의 면적·t/m²·부지 치수 |
| ⑥ 마스터플랜 | 띠 적층 배치 · 드래그로 순서 변경 · 면적 분해 |
| ⑦ 3D 부지 | 실형상 3D · 이동기기 애니메이션 |
| ⑧ 민감도·시나리오 | 한 변수 변화에 따른 면적 계단 · A/B 비교 |

내보내기: 도면 PNG/SVG · 계산서 CSV · 시나리오 JSON · A3 가로 인쇄

## 설계 원칙

- **모든 출력 숫자는 근거를 들고 다닌다.** `res(값, 단위, 식, 대입, 출처)` 객체로 만들어
  화면에서 계산식·대입값·출처를 펼쳐 볼 수 있다.
- **도면은 미터 좌표 + viewBox 축척.** 실비례가 코드 수준에서 보장된다.
- **글씨 크기는 viewBox 폭의 1/46.** `fs = 콘텐츠폭 / (46 − 여백단위합)` 으로 잡아
  여백·범례 크기와 무관하게 모든 도면이 화면에서 같은 크기로 보인다.
  도면 1장당 글씨는 치수 `fs`, 주기 `fa = 0.8·fs` 두 종류만 쓴다.
- **외부 의존성 없음.** 빌드는 파이썬 표준 라이브러리, 시험은 node 내장 모듈만.

## 데이터에 관하여

프리셋과 검증 항목은 **예시값**입니다. 실제 프로젝트 자료가 아니며,
`verification` 탭·시험은 "엔진이 예전과 같은 값을 낸다"는 **회귀 검사**로 동작합니다.

원료 비중·안식각 등 물성값도 공개 대표값이므로 **프로젝트별로 반드시 재확인**하십시오.
